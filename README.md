# esp-idf-lib/ccs811

Driver for AMS CCS811 digital gas sensor.

* [Documentation](https://esp-idf-lib.github.io/ccs811/)
* [Repository](https://github.com/esp-idf-lib/ccs811)
* [Issues](https://github.com/esp-idf-lib/ccs811/issues)
* [Discussions and questions](https://github.com/esp-idf-lib/core/discussions)
* [Component page at the ESP Component Registry](https://components.espressif.com/components/esp-idf-lib/ccs811)

## Installation

```sh
idf.py add-dependency "esp-idf-lib/ccs811^1.0.0
```
